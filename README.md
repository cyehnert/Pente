This code enable the user to play a game of Pente versus the computer. The code has been recently
enhanced with a new GUI with buttons for selecting which player goes first, and whether or not to
use capture rules. The program also records the moves of the game in a text file that can be saved.
The game is played on a 13 x 13 GO board, and stones are placed at grid intersection. The winner is 
the first play to achieve 5 stones in a row or to capture 5 pairs of stones, if capture rules are
selected.
